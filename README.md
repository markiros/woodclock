# WoodClock — скринсейвер для macOS

Аналоговые часы: четыре пресета в стиле «дерево + золото + стекло» «Вокзальные» (белый циферблат, серый корпус, квадратные цифры) «Слоновая кость» (кремовый корпус, цифры с засечками, гирлянда роз) «Красное дерево» (тот же рисунок в тёмном красном дереве и золоте) «Тёмный лак» (рисунок «Слоновой кости» в рамке из тёмного лакированного дерева) «Бронзовое кружево» (ажурная бронзовая рама, вырезанная из фото, букет розовых роз) «Неон» (без корпуса: светящиеся зелёные метки и стрелки на чёрном) и «Неон, пунктир» (то же, секундная стрелка из точек). Слои циферблата и стрелок — готовые PNG, вращение стрелок делает Core Animation, поэтому нагрузка на CPU минимальная.

## Сборка и установка

Нужны Xcode (или Command Line Tools + Xcode SDK) и XcodeGen:

```bash
brew install xcodegen
make install        # собирает universal (arm64 + x86_64) и копирует в ~/Library/Screen Savers
```

Дальше: «Системные настройки → Заставка → WoodClock → Параметры».

`make uninstall` — удалить, `make clean` — убрать сборку и сгенерированный .xcodeproj.

## Настройки скринсейвера

- **Циферблат** — пресет из `WoodClock/Presets` (по умолчанию «Орех и латунь»), с превью.
- **Секундная стрелка** — плавно / шагом / скрыть. В режиме «шагом» можно включить «Дрожание при шаге»: стрелка проскакивает отметку и затухающе качается, как у кварцевых часов.
- **Размер** — диаметр часов в процентах от меньшей стороны экрана.

## Структура пресета

```
WoodClock/Presets/<id>/
  preset.json        имя, список слоёв, размеры и оси вращения
  dial.png           корпус, безель, дерево, разметка, цифры
  hour.png           часовая стрелка        + hour_shadow.png
  minute.png         минутная стрелка       + minute_shadow.png
  second.png         секундная стрелка      + second_shadow.png
  cap.png            центральная втулка
  glass.png          стекло с бликом (поверх всего)
  preview.png        превью для окна настроек
```

Слои рисуются в порядке из `preset.json`. В `size` — размер слоя в долях от холста часов, в `anchor` — ось вращения в долях картинки от левого верхнего угла. Тени стрелок — отдельные картинки, которые вращаются вокруг своей оси, но смещены в постоянную сторону, поэтому свет всегда падает сверху-слева, как у настоящих часов.

Чтобы добавить пресет, положите новую папку с такой же структурой и пересоберите. Код менять не нужно.

## Перерендер PNG

Исходник всех циферблатов — `tools/dial.js` (SVG-генератор), живой прототип — `tools/prototypes.html`.

```bash
pip3 install pillow playwright && python3 -m playwright install chromium
# шрифты Bodoni Moda, Cormorant Garamond и Orbitron должны быть установлены в системе (для «Слоновой кости», «Красного дерева», «Тёмного лака» и «Бронзового кружева» — Bodoni 72, есть в macOS)
# перерендер только части вариантов: python3 tools/render.py WoodClock/Presets F G H I J K
make presets
python3 tools/compose_check.py WoodClock/Presets check.png   # собрать кадр из слоёв для проверки
```

Холст рендерится в 1600×1600 px: этого хватает на часы до ~800 pt на Retina.
